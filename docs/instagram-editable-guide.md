# ✏️ دليل التعديل على بوستات لوموند

عندك نسختان من نفس التصاميم الـ ١٥ — واحدة للنشر المباشر، وواحدة للتعديل بنفسك.

| الملف | الاستخدام | التعديل |
|------|-----------|---------|
| `out/instagram/IG01..IG15.png` | النشر المباشر على إنستقرام | عبر الكود ثم إعادة رندر |
| `out/instagram/lomond-instagram-editable.pptx` | التعديل في كانفا / باوربوينت / Google Slides | سحب وإفلات، كل النصوص حية |

---

## 🎨 التعديل في كانفا

1. افتحي [canva.com](https://canva.com) → **Create a design** → **Import file**
2. اسحبي ملف `lomond-instagram-editable.pptx`
3. كانفا تفتحه كتصميم من ١٥ صفحة، **كل نص قابل للنقر والتعديل**
4. عدّلي الأسعار، الأسماء، النصوص… ثم **Share → Download → PNG** بجودة عالية

**كل صفحة بمقاس ١٠٨٠×١٣٥٠ بكسل** — وهو مقاس إنستقرام ٤:٥ المثالي (يأخذ أكبر
مساحة ممكنة في الفيد).

### الخطوط داخل الملف

| الاستخدام | الخط | ملاحظة |
|-----------|------|--------|
| العناوين العربية | **Amiri** | سيريف عربي فاخر — متوفر في كانفا |
| النصوص العربية | **Tajawal** | سانس عربي نظيف — متوفر في كانفا |
| اللاتيني والأرقام | **Times New Roman** | متوفر في كانفا وفي كل أجهزة ويندوز/ماك |

> إذا طلبت منك كانفا استبدال خط مفقود، اختاري البديل من نفس العائلة
> (Amiri → أي سيريف عربي، Tajawal → Cairo أو Almarai).

## 🖥️ التعديل عبر الكود (النسخة الأدق)

التصاميم مبنية بـ **Remotion** (React)، فأي تعديل ينعكس على كل البوستات دفعة واحدة.

```bash
npm install
npm run dev          # استوديو تفاعلي للمعاينة الحية على المتصفح
npm run render:ig    # تصدير الـ ١٥ بوست PNG بدقة ٢١٦٠×٢٧٠٠
npm run build:pptx   # إعادة توليد ملف الـ PPTX القابل للتعديل
```

| أبغى أغيّر… | الملف |
|-------------|-------|
| الألوان أو الخطوط | `src/theme.ts` |
| نصوص وتصميم البوستات | `src/instagram/posts.tsx` |
| العناصر المشتركة (الإطار، الأزرار، الشعار) | `src/instagram/IgAtoms.tsx` |
| ملف كانفا | `tools/build-pptx.js` |

### فحص الجودة

```bash
npm run check:pptx   # يتحقق من الحدود وفيض النصوص داخل ملف الـ PPTX
```

## 📐 قواعد الهوية المطبّقة في كل بوست

1. **إطار مزدوج** — خط ٢px خارجي + هيرلاين ١px داخلي. هذا توقيع لوموند البصري
   الذي يميز الفيد فوراً عن المنافسين.
2. **الشعار أعلى كل بوست** بعرض ثابت، وتحته سطر التصنيف العربي ثم سطر لاتيني
   سيريف بأحرف كبيرة متباعدة (`THE LOMOND GUIDE` / `THE COLLECTION`).
3. **البرقندي `#4D0E13` هو المرساة** — يُستخدم للبوستات الداكنة فقط (١، ٩، ١٥)
   وللعناوين والأزرار على البوستات الفاتحة.
4. **الأرقام والأسعار بخط سيريف Times** — التباين مع العربي يعطي الطابع التحريري
   الفاخر بدل شكل «تصميم كانفا الجاهز».
5. **بدون إيموجي داخل التصاميم** — الإيموجي مكانه الكابشن فقط.
6. **ذيل موحّد**: `Lomond · Fine Jewellery · KSA`

## 🔁 استبدال الرسومات بصور المنتجات الحقيقية

بوستات المنتجات (٤، ٦، ١٠، ١٤) فيها حالياً رسمة SVG داخل دائرة بيضاء.
عند توفر التصوير الاحترافي:

**في كانفا:** انقري على الرسمة → احذفيها → اسحبي صورتك مكانها داخل نفس الدائرة.

**في الكود:** استبدلي مكوّن الرسمة في `ProductPost` بـ:

```tsx
<Img src={staticFile('products/solitaire.jpg')} style={{width: 440, height: 440,
  borderRadius: '50%', objectFit: 'cover'}} />
```

ثم ضعي الصور في `public/products/`.
